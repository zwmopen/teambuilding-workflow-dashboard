# 团建内容工作台

江湖有旅人团建内容生产、作品集库存和设备分发的本地桌面工作台。所有页面既能手动操作，也保留可复制给 Codex 的自然语言入口。

## 当前功能

- 素材生产：默认启动页；可选择或粘贴任意本地素材目录并递归扫描，左侧以紧凑列表或小图标浏览帖子，桌面版右侧直接显示真实 ChatGPT 网页、登录会话和现有网页脚本。
- 作品集：实时读取小红书、抖音、公众号 Junction、归档目录和 CSV 日志，并提供并行 JSON 台账编辑人工分类、标签与备注。
- 分发功能：后台自动刷新设备状态；在线设备置顶，离线操作禁用。支持随机补笔记、指定作品包发送、普通文件/文件夹上传和拖放；两类传输都显示实时阶段、百分比、停止与结果记录，真实传输继续调用 `device-folder-transfer`。
- 发布复盘：进入聚光运营和生产日志。
- 设置：维护素材目录、现有一键工作包的作品集目录/成组规则，并在 6 套差异化主题间切换。

作品集名称不会被工作台修改，也不会另建一套标签数据库。内容类型来自名称末尾的 `[泛]` / `[转]`；平台状态来自真实入口和日志。

## 0.6 桌面双栏模式

- 双击 `start.vbs` 默认启动桌面应用。
- 仅在“素材生产”显示右侧真实 ChatGPT 网页；切换到作品集、分发功能等页面时自动隐藏。
- ChatGPT 提供 3 个隔离的登录空间，账号 Cookie 和缓存只保存在本机。
- 浏览器版 `http://127.0.0.1:4327` 继续保留，便于调试和兼容旧流程。
- 作品集标签可导出为 UTF-8 CSV，Excel 可直接打开。
- 浏览器版不会用仿制聊天卡冒充 ChatGPT；真实内嵌网页只在桌面应用的安全隔离浏览器空间中显示。

## 分发安全

- 手机补笔记按钮调用共享 `device-folder-transfer`，不复制传输与 Junction 清理逻辑。
- 真正发送前界面会再次确认；只有接收确认成功，Skill 才会处理对应平台入口。
- 发送确认、错误提示和重命名都使用软件内部弹层，不显示脚本、软链接或原始命令行输出。
- 作品包发送前会创建独占占用记录；已有占用或 `device-usage-log.csv` 成功记录时拒绝发送，防止并发、崩溃或入口误建造成重复。
- 小红书与抖音属于同一手机使用组：只有双平台入口同时有效的作品包可分发，任一平台使用后整组作废；公众号属于独立组，可继续单独使用。
- 公众号补笔记先登记“已打开过”；必须人工确认上传完成后才记为“上传已完成”。
- 源作品集不会被工作台删除。
- 手机分发成功后不再创建抖音归档入口；旧异常入口保持可见但不会进入可分发库存。
