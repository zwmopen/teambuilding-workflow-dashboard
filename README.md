# 团建工作台

江湖有旅人的本地团建业务工作台，统一承载素材生产、作品分发与流量转化。各业务数据继续由原项目和独立知识库维护，工作台负责提供一套一致的使用入口。

## 为什么要做这个软件

过去一篇团建内容要在素材文件夹、ChatGPT 对话、模板记录、成品目录、手机传送工具和转化知识库之间来回切换。真正费时间的并不是“点一下生成”，而是反复寻找文件、确认模板、核对是否用过、把作品传到正确设备，以及记住作品下一步该去哪里。

团建工作台把这些步骤收进同一个本地界面：

1. 左边选择真实素材和永久母版；
2. 中间生成逐页计划，确认后生产整套封面与内页；
3. 右边查看包含图片、TXT 文案和生产记录的真实帖子文件夹；
4. 打包后进入内容分发，发送到已确认的手机；
5. 手机确认接收后，电脑端作品自动进入微信公众号阶段；
6. 搜话术、走转化 SOP 和找方案时，直接进入同一个工作台里的“流量转化”。

它不是网盘，也不是另一套素材数据库。文件夹仍是事实真源，软件只是把真实文件和已经验证的工作方法组织得更清楚。

## 适合谁

- 日常批量制作小红书/抖音团建图文的人；
- 需要固定母版、多批素材持续迁移的运营人员；
- 同时管理电脑库存、多个自有手机和公众号发布阶段的人；
- 希望内容生产、分发、前端话术与后端转化在同一个系统里完成的人。

## 第一次使用：先做这五步

1. 双击桌面的“团建工作台”。
2. 在“内容制作”右上角设置里确认素材库、模板库、成品库和已打包库。
3. 左侧勾选一个或多个素材文件夹，再选择一套母版。
4. 点击“开始生产”查看逐页计划，再点击“生成首张校准图（仅1次调用）”。
5. 先检查首张封面；满意后点击“首图确认无误，继续生成剩余 N 张”，最后在右侧展开成品文件夹检查图片与 TXT 并打包。

内容分发第一次使用时，先在设备卡片中核对手机备注。陌生设备默认不能接收作品；已登记、已确认的设备才会进入白名单。

## 日常最快用法

- 正式使用请从桌面图标进入 4327；它启动已验收的便携正式版，不会随着源码保存自动变化。
- 日常开发使用源码端口 4337；保存修改后刷新开发页即可热更新，确认无误并重新发布后才更新桌面正式版。
- 需要沿用原来“在同一 GPT 会话里反复迁移母版”的方式时，进入“内容制作（GPT内置测试）”：左侧勾选一个或多个素材文件夹、选择一个母版，右侧首次登录一次 ChatGPT，之后登录状态会保留。点击“送入 GPT”后会按素材逐组排队，不需要再手工逐张上传。
- 所有目录输入框都支持粘贴后按回车，或点到输入框外自动保存；“选择”会打开 Windows 文件夹选择器。
- 内容制作左侧只给文件夹复选框；展开后的图片和 TXT 不需要复选框，点击即可预览。
- 内容分发中点击作品集整行即可选中，选中后整张卡片上浮；分类、打开和发送操作保持同一高度。
- 右下角“团建中控助手”支持自然语言执行安全命令，例如“你能干嘛”“现在还有多少作品”“检测在线设备”“给 4 号发一个精准流量作品”“打开内容分发设置”。明确指令直接识别，其他说法由当前文本模型归类到允许动作；发送仍复用同一套设备白名单、防重复和接收确认规则，模型不能执行任意系统命令。

### GPT 内置测试与 API 生产的区别

- “内容制作”使用配置的图片 API，适合自动化、可恢复和成本审计；先生成首图校准，再由用户确认是否继续整套。
- “内容制作（GPT内置测试）”使用真实 ChatGPT 网页额度和现有会话能力，适合复用母版对话式生产；工作台只负责选择本地文件、组装提示词、顺序送入与接收状态，不接触账号凭据。
- 两条生产链互不替代，也不共用登录密钥。内置页首次登录后由 Electron 的独立 Chromium 分区保存会话；源码、日志和发布仓库不会保存 Cookie。
- 正式便携版内置扩展运行快照，不依赖旁边必须存在扩展源码仓库。发布前运行 `scripts/sync-gpt-extension.ps1`，把扩展的已验收版本同步进安装包；开发模式仍优先读取独立扩展源码。

## 生图接口到底怎么配合

工作台把“理解内容”和“生成图片”拆成两件事：

1. **文案模型**读取素材文件夹里的图片、TXT 和文件夹名称，负责提炼作品标题、逐页标题和小红书正文；
2. **生图模型**接收当前页的母版参考图、素材参考图和已经整理好的页面要求，返回一张新的 AI 图片；
3. 工作台把每页独立保存，再做张数、尺寸、文件可读性和失败页检查。

所以纯生图接口当然能接收文字提示词，但它不适合独自承担长文案分析、整个项目记忆和批量任务管理。把文案模型和生图模型分开，能让同一份模板规则重复使用，也避免每一页都重新发送整段历史对话，消耗更小。

当前支持三路图片平台：

| 平台 | 默认模型 | 模板参考图 | 用途 |
|---|---|---:|---|
| 本机 OpenAI 兼容接口 | `gpt-image-2` | 支持 | 日常本机生产与接口对照 |
| ByteCat | `gpt-image-2` | 支持，使用 JSON 参考图协议 | 外部稳定通道与批量生产 |
| MiniMax | `image-01` | 当前实现以文字生成为主 | 备用平台；必须先有有效官方密钥 |

同一个生产任务只会使用用户当次选择的平台，不会失败后偷偷换成另一家，也不会用原素材复制件冒充 AI 成品。接口失败会保留失败页和错误原因，其他页继续生产，修好接口后可以只补缺页。

### 为什么不需要像 ChatGPT 对话那样反复上传整套模板

母版文件夹和母版配方都保存在本机。每次生产时，工作台自动挑选封面母版或典型内页母版，再和当前素材页组合成轻量参考板。用户只需要：

1. 选择一套模板；
2. 在左侧勾选一个或多个素材文件夹；
3. 生成计划并确认。

一套模板可以连续迁移到多组素材。任务、提示词、结果和失败页都写入本地运行数据，因此关闭软件后仍能恢复，不依赖某一个网页聊天窗口一直开着。

### 怎么控制耗时和消耗

- 正式批量前只生成第一套作品的 P1 封面；首图成功后强制暂停，不会因左侧选择很多素材就直接跑完整批；
- 付费生图请求不自动重试；首图失败时只保留错误与尝试记录，由用户决定是否再试一次；
- 每页只发送一张母版图和一张当前素材图，不把整个模板库、整套素材和历史成品重复上传；
- 母版与素材会先在本机压缩成轻量参考板，再交给支持参考图的接口；
- 文案每套只生成一次，不为每一页重复调用；
- 已经成功落盘的页面在继续任务时会跳过，只补缺页；
- `生产记录.json` 会记录实际生成请求数、尝试次数、参考图数量和接口返回用量（平台提供时）；
- 先在“API 对比测试”中用同一套素材核对速度和稳定性，再决定日常默认平台。

## 文件是怎么流转的

```text
素材库 + 模板库
      ↓
API生产待审 / 正式成品库（未打包）
      ↓ 人工检查并打包
抖音小红书（手机待发）
      ↓ 手机确认接收
微信公众号
      ↓ 确认三端发布
已发送 ZIP
```

“操作记录”是审计历史，不是第二套状态。当前作品在哪个真实文件夹，就处于哪个阶段。

## 自动备份怎么工作

设置页提供两类备份：

- **工作台小数据备份**：设置、提示词、任务索引、设备备注、分发记录和防重复账本。默认每天检查一次。
- **方案文件增量备份**：用户指定一个本地方案目录，系统按相对路径逐个上传变更文件。它可以和“流量转化 → 按需求找方案”共用同一个企微微盘同步目录；默认每月最多上传 2560MB，达到上限的文件留到下个月继续，不覆盖本地原件。

备份目标是坚果云 WebDAV 下的“团建内容工作台”独立目录。账号密码使用 Windows 当前账户加密保存，不显示在界面、不写入仓库。打包应用会沿用本机代理环境；若连接返回 401，表示坚果云应用密码已经失效；返回 403 时会提示检查云端上传流量、空间额度或目录写入权限。失败会保留增量清单，额度或权限恢复后可以继续，不会伪造成功记录。

大文件清单记录在运行数据目录中，用“相对路径 + 大小 + 修改时间”判断是否需要再次上传。软链接不会跟随上传，避免意外把目录外文件带入备份。

## 使用技巧

- 一套模板可以对应多个素材文件夹；生产数量由左侧已选素材决定，不需要再选择“做一套/批量做”。
- 模板只决定视觉骨架，素材只决定内容。历史生成结果不会自动升级为新母版。
- 真实景点页优先保留原场地、道路、建筑和设施关系；普通玩法页才允许更强的人物与道具去重。
- 价格只有素材或文案明确提供时才写；人数和业务范围按当前业务规则统一。
- 生成任务较慢时看中栏百分比、当前阶段和最近日志，不要重复点击确认。
- 成品/失败任务会在当前操作区保留 3 分钟，也可以手动清除；完整历史继续保留在“操作记录”。
- 正式更新前先确认没有正在运行的生产或分发任务，避免手机卡在接收中或留下未完成占用。

## 当前功能

- 素材生产三栏工作台：左侧自动读取本地素材，点击分类或模板后在该条目下方横向展开无标题缩略图，点击缩略图查看大图；中间只放模板规则、本批要求以及彼此独立的生图平台/生图模型/文案模型；右侧查看真实待审/成品文件夹并多选打包到抖音小红书待发。
- 待发打包：完整复制每个作品文件夹的独立图片、文案、出图计划和生产记录；同名作品不覆盖，操作写入流水线审计记录。
- 素材生产：先轻量列出顶层素材库，展开或切换哪个分类才递归读取哪个分类，以紧凑文件树浏览“图片 + 文案”的帖子文件夹。
- 本地作品生产：作品数量直接跟随左侧已选素材文件夹，不再显示“做一套 / 批量做”模式控件。系统先按素材事实和模板配方生成可读的出图计划，确认后在后台逐页生产。
- 生产确认：首次点击“开始生产”只生成逐页计划；第二步只生成第一个素材的 P1 校准封面并暂停；确认首图后才继续剩余页面，同一操作区始终提供明确按钮和剩余张数。
- 模板配方：已把长期对话里反复验证的米字格、绿底键帽、森林路线节点等母版规则结构化；用户不需要理解 A/B/C、校准提示词或接口参数。
- 作品落盘：每个左侧已选素材文件夹对应一个待审作品文件夹，生成 `P1…Px` 独立 3:4 图片、`小红书文案.txt`、`出图计划.json` 和 `生产记录.json`；不会把多页合成一张总图。
- 模型选择：主生产区可切换本地 GPT、ByteCat 和 MiniMax，并从当前平台读取可用生图模型；文案模型独立选择，不会因图片平台切换而被绑死。密钥只保存在运行数据的安全凭据文件，不回传界面、不进入仓库。
- 生图费用保护：付费生成 POST 每页最多发起一次，408、429、500、502、503、504 或网络错误不会自动重复扣费；失败页保留可读原因、尝试记录和手动重试入口。
- 素材元数据：每个帖子文件夹以独有文件夹哈希绑定唯一母标签和使用次数；聚会游戏、破冰游戏等统一归入“团建游戏”，人工选择在改名或移动后继续保留。
- 全库筛选：后台逐分类建立轻量索引，并从既有素材链接记录和制作日志自动回填可靠使用次数；不能唯一对应当前文件夹的历史只列入待核对。
- 分发库存：在“内容分发”内按“抖音小红书 → 微信公众号 → 已发送”三个真实文件阶段切换；手机确认接收和公众号人工标记会搬动原始作品文件夹，资源管理器中的移动也会反向同步到工作台。
- 流量转化：以同源模块完整融入工作台；原侧栏功能改为顶部标签，搜索、SOP、需求方案和用户旅程均可在同一页面直接点击与维护。外层不再套独立卡片底板，转化内容与工作台共享同一块大背景。聊天来源、方案来源和知识入库分别回到对应业务页。
- 内容分发：后台自动刷新设备状态；本轮发现与 10 分钟内最近发现分开显示，避免手机后台节流造成设备闪退。支持随机补笔记、指定作品包发送、普通文件/文件夹上传和拖放；两类传输都显示实时阶段、百分比、停止与结果记录，真实传输继续调用 `device-folder-transfer`。`[转]` 在界面统一称为“精准流量（业务类）”，表示偏业务承接的内容。
- 连接方式：设备卡片和选择窗口显示真实 Wi‑Fi、USB 与远程标签；只有实际发现或接入的方式显示在线，USB 大文件备用和尚未接入的远程能力会明确区分。
- 防重复：生产端只读汇总既有 193 组图片历史（整组 SHA-256 确定重复、64 位 dHash 近似预警）；分发端独立记录手机组、公众号组和传输结果。
- 插件市场：集中管理生产链上的独立浏览器扩展、本地软件与脚本，可直接打开本地目录、安装包、发布页或开源仓库。
- 设置：集中维护全局 API/模型、素材与成品默认目录、坚果云备份、本地防重数据与软件诊断；各业务页面的本地来源路径独立设置，互不覆盖。

作品集名称不会被工作台修改，也不会另建一套标签数据库。内容类型来自名称末尾的 `[泛]` / `[转]`；平台状态来自真实入口和日志。

## 工作台与“团建 GPT 数字作品生产助手”

- 双击桌面的“团建工作台”启动本地源码版；保存代码后刷新页面即可看到热更新，无需重新打包。
- 日常 ChatGPT 协作使用 Chrome / Edge 里的真实 `chatgpt.com`，Google 登录由正常浏览器完成，不再依赖容易被 Google 判定为“不安全”的内嵌浏览器。
- 桌面工作台已完全移除右侧 ChatGPT 内嵌网页和多账号登录壳；点击“传 GPT”会准备生产指令并打开系统默认的真实浏览器，由独立扩展接管上传与会话协作。
- 独立项目 `D:\AICode\工具开发\projects\teambuilding-gpt-production-extension` 专门服务“生产数字作品”SOP，不属于本工作台源码。
- 扩展保留 ChatGPT 原生左侧会话和中间对话，只在右侧增加成品/素材生产舱；点击或拖动会把本地图片、TXT/Markdown 和生产指令放进当前对话。
- 扩展只读取 `127.0.0.1:4327` 的授权目录、文件流和去重状态接口；设备分发仍由本地中控管理。
- 旧油猴脚本、VBS 和 PowerShell 不删除，可继续作为回退路径。完成扩展验收前，不要同时启用两份相同网页按钮。

### 首次安装数字作品生产助手

1. 打开 Chrome / Edge 的扩展管理页并开启“开发人员模式”。
2. 选择“加载已解压的扩展”，指向独立扩展项目的 `src` 目录。
3. 打开真实 ChatGPT 页面；原生左侧会话保持不变，右侧出现“数字作品生产舱”后即可使用。

浏览器安全策略要求用户本人确认一次扩展安装。之后登录状态由正常浏览器管理，中控台不保存 Google 或 ChatGPT 密码。

## 分发安全

- 手机补笔记按钮调用共享 `device-folder-transfer`，不复制传输与 Junction 清理逻辑。
- 真正发送前界面会再次确认；只有接收确认成功，Skill 才会处理对应平台入口。
- 发送确认、错误提示和重命名都使用软件内部弹层，不显示脚本、软链接或原始命令行输出。
- 作品包发送前会创建独占占用记录；已有占用或 `device-usage-log.csv` 成功记录时拒绝发送，防止并发、崩溃或入口误建造成重复。
- 小红书与抖音属于同一手机使用组：只有双平台入口同时有效的作品包可分发，任一平台使用后整组作废；公众号属于独立组，可继续单独使用。
- 公众号补笔记先登记“已打开过”；必须人工确认上传完成后才记为“上传已完成”。
- 源作品集不会被工作台删除。
- 手机分发成功后不再创建抖音归档入口；旧异常入口保持可见但不会进入可分发库存。
