# 团建内容工作台

江湖有旅人团建内容生产、作品集库存和设备分发的本地桌面工作台。所有页面既能手动操作，也保留可复制给 Codex 的自然语言入口。

## 当前功能

- 总览：只汇总本地可验证状态，不推测 ChatGPT 网页内部进度。
- 素材生产：读取本地素材树、模板、生产记录和成品预览。
- 作品集：实时读取小红书、抖音、公众号 Junction、归档目录和 CSV 日志。
- 分发功能：扫描已登记设备和在线数量，调用现有 `device-folder-transfer` 完成手机补笔记或公众号领取。
- 发布复盘：进入聚光运营和生产日志。
- 设置：切换雾绿实体、轻透玻璃和柔和拟态主题。

作品集名称不会被工作台修改，也不会另建一套标签数据库。内容类型来自名称末尾的 `[泛]` / `[转]`；平台状态来自真实入口和日志。

## 边界

- 控制台状态、提示词版本索引和服务日志：`D:\AICode\运行数据\江湖有旅人\图文生产控制台`
- 团建生产方法：`D:\AICode\AI\skills\技能包\技能\teambuilding-xhs-workflow`
- 分发执行方法：`D:\AICode\AI\skills\技能包\技能\device-folder-transfer`

软件不复制业务资产，只读取项目真源并保存自己的界面状态。

## 启动

双击 `start.vbs` 或桌面的“团建图文生产控制台”。服务地址为 `http://127.0.0.1:4327`。

命令行启动：

```powershell
& 'D:\AICode\工具开发\projects\teambuilding-workflow-dashboard\start.ps1'
```

## 验收

```powershell
node --check .\src\server.js
Set-Location .\src
npm test
```

启动后应能读取当前项目的素材、模板、作品集、生产日志和分发日志，并把可变状态写入运行数据目录。

## 分发安全

- 手机补笔记按钮调用共享 `device-folder-transfer`，不复制传输与 Junction 清理逻辑。
- 真正发送前界面会再次确认；只有接收确认成功，Skill 才会处理对应平台入口。
- 公众号领取只登记“已领取待电脑上传”；必须人工点击“确认上传完成”后才记为已确认上传。
- 源作品集不会被工作台删除。
- 当前归档恢复仍保持只读：检测到入口异常时不会提供恢复按钮，需先修复源目录或由 Skill 安全恢复。
