# 设计说明

## 目标

把团建内容生产的素材、模板、成品、日志和提示词集中呈现在一个本地控制台，降低续接生产和检查缺页时的寻找成本。

## 分层

控制台只是一层界面和状态机。项目推进目录是业务事实真源；共享 Skill 是工作流规则真源；运行数据目录承载可重建状态和日志。三者不互相复制。

## 原则

1. 不移动或改写业务素材结构。
2. 所有根路径允许通过环境变量覆盖。
3. 可变状态不写入源码仓库。
4. 打开本地路径前执行允许根目录校验。
5. 旧项目入口迁移后只做兼容转发。

## 环境变量

- `TEAMBUILDING_ROOT`：业务项目根目录。
- `TEAMBUILDING_SKILL_ROOT`：团建提示词资料根目录。
- `TEAMBUILDING_DASHBOARD_RUNTIME`：控制台状态和日志目录。
- `PORT`：HTTP 服务端口，默认 `4327`。
