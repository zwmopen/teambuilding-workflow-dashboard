# 设计说明

## 0.9.9 双视觉语言、说明系统与插件市场

- 视觉只保留“拟态”和“玻璃”：两者共用冷灰蓝色板、圆角和信息层级，差异只在实体柔和阴影与半透明悬浮材质。
- 左侧导航选中态使用浅蓝面与蓝色强调，不使用大面积黑色；页面按钮和卡片跟随当前主题。
- 帮助不是装饰问号，而是产品说明入口：每页交代为什么存在、遵循什么方法、真实数据在哪里、用户怎么做以及动作是否影响文件。
- 插件市场不是在线商店，而是本地生产工具目录；只登记已核对路径、版本和来源，测试资产必须标注测试状态。
- 坚果云配置复用人生游戏系统，但凭据不跨仓库复制：一次导入后交由 Windows 当前账户加密保存；工作台使用独立子目录，不覆盖其他产品的备份。

## 0.9.8 文件夹分发工作台

- 分发页不再以“手机补笔记 / 公众号补笔记”的操作员术语组织，而以设备和三个真实文件夹阶段组织。
- 顶部五个入口固定为设备、抖音小红书、微信公众号、已发送、操作记录；目录数量来自磁盘即时快照。
- 抖音小红书、微信公众号内部按泛流量帖、精准流量帖、未分类切换；修改分类会同步修改真实文件夹名，不建立平行虚拟标签。
- 操作记录只承担审计作用，不能覆盖文件夹事实；归档仍执行“先生成并校验 ZIP，再删除源目录”。
- 页面帮助采用统一“说明”入口，说明当前页面怎么用、数据从哪里来以及哪些动作会移动、改名或删除文件。

## 0.9.4 真实连接标识与发送闭环

- 素材生产不再在桌面壳右侧嵌入 ChatGPT；本地素材选择、预览和指令准备保留在工作台，账号登录与真实对话统一进入 Chrome/Edge 扩展。
- 素材生产页以“模板是样式、素材是内容”为核心，固定展示模板 → 素材 → 生图 API → 作品/文案四步；未配置接口时只显示待接入，不提供虚假生产结果。
- 设备卡片与选择设备窗口使用紧凑图标标签区分 Wi‑Fi、USB 和远程连接，不再以笼统的“在线”代替传输方式。
- 只有局域网真实发现的设备显示 Wi‑Fi 在线；USB 仅在实际连接时显示在线，旧 iPhone 的大文件 USB 自动备用明确标为备用能力；远程未接入时显示待接入。
- 作品包发送成功以手机接收确认和 `device-usage-log.csv` 为准，随后物理移动到公众号文件夹；日志、独占占用和文件夹阶段共同防止重复发送。

## 0.9.3 三阶段文件流水线

- 作品集顶部固定为“抖音、小红书 / 公众号 / 已使用”三个标签，阶段即文件夹，不另建平行状态数据库。
- 手机确认接收成功后，原始作品目录进入公众号；人工标记公众号已使用后进入已使用。
- 工作台动作与资源管理器移动双向一致；日志只记录事件，不覆盖磁盘阶段事实。
- 原始目录移动采用同卷原子改名；同名目标存在时停止，不覆盖用户文件。

## 0.9.2 全库索引与历史证据

- 工作台启动继续保持浅扫描；全库索引由扩展需要时在后台逐分类建立。
- 使用次数不是手工记忆值，而是可追溯生产事件数；相同素材 ID、时间和模板视为同一事件。
- 旧路径失效后只做唯一精确名称匹配，模糊或多候选结果交给待核对。
- 回填只写运行数据台账和索引，不修改用户素材文件夹。

## 0.9.1 素材母标签与按需加载

- 一个素材文件夹只有一个母标签：团建游戏、团建转化或合集攻略。
- 同义游戏目录统一归入团建游戏，不把“聚会游戏、破冰游戏”等作为并列母标签。
- 文件夹唯一哈希是稳定身份；标签和次数写入运行数据，不污染素材目录结构。
- 自动识别提供默认值，人工选择拥有更高优先级。

## 目标

把团建内容生产、作品集库存、设备分发和公众号补笔记集中在一个本地工作台，降低寻找目录、判断资格和重复点击的成本。

## 分层

工作台只是一层界面和状态机。项目推进目录是业务事实真源；共享 Skill 是工作流规则真源；运行数据目录承载可重建状态和日志。三者不互相复制。

## 界面

- 设置集中在一个页面：上方是拟态/玻璃两种显示模式，中部是目录、坚果云和自动化规则，下方是数据、扩展、版本和高级入口。
- 素材区遵循“先看分类、再读内容”：首次打开只读取当前分类，切换或展开时再加载目标分类，并保留文件夹原结构。
- 左侧工作流固定为素材生产、作品集、分发功能和设置；素材生产是默认入口。
- “生产数字作品”由独立浏览器扩展服务；工作台提供本机目录、文件流、历史状态和回退入口。
- 浏览器调试版不绘制假的聊天记录，也不伪装成已经接入的 ChatGPT。
- 作品集负责库存、平台资格和历史；分发功能负责执行与记录。
- 手动按钮和 Codex 指令必须调用同一套规则。
- 视觉默认采用冷灰蓝拟态，并可切换半透明玻璃主题；控件保持紧凑、低对比和清楚的选中态。
- 确认、输入、错误和完成反馈统一使用软件内部弹层，不调用浏览器原生对话框，不向用户暴露执行内核术语。

## 原则

1. 不移动或改写业务素材结构。
2. 所有根路径允许通过环境变量覆盖。
3. 可变状态不写入源码仓库。
4. 打开本地路径前执行允许根目录校验。
5. 分发不复制共享 Skill 的传输和 Junction 清理逻辑。
6. 公众号“已打开过”不等于上传完成，必须人工确认。
7. 所有需要人工寻找和切换的外部操作统一归口到工作台，但不复制出第二份可独立修改的源码。
8. 已经跑通的油猴、VBS、PowerShell、本地协议和共享 Skill 优先作为执行内核直接复用；工作台负责入口、参数、任务绑定、进度和结果。
9. 外部能力按“直接调用 → 适配器联动 → 稳定后内建模块”渐进升级，每一步都保留旧入口和恢复路径。
10. 网页能力必须使用真实网页和真实登录会话；浏览器扩展、桌面工作台和共享 Skill 分别维护独立产品边界。
11. 任何真实分发必须先建立可见任务；任务至少显示目标、当前阶段、百分比、停止入口和最终结果，页面刷新后仍可恢复。

## 环境变量

- `TEAMBUILDING_ROOT`：业务项目根目录。
- `TEAMBUILDING_SKILL_ROOT`：团建提示词资料根目录。
- `TEAMBUILDING_DASHBOARD_RUNTIME`：控制台状态和日志目录。
- `TEAMBUILDING_PUBLISH_ROOT`：发布空间目录。
- `DEVICE_TRANSFER_SKILL_ROOT`：设备分发 Skill 目录。
- `PORT`：HTTP 服务端口，默认 `4327`。
# 0.9.6 生产入口设计

素材生产页的首要动作是“得到什么”，不是“调用什么接口”：

- 做一张：用户选择封面或内页，适合补页、单张发布或快速验证。
- 做一套：系统按有效素材拆分页面，输出独立轮播图片、文案和记录。
- 批量做：从当前素材开始连续处理多套，统一使用当前模板配方。

第一次点击生成计划，第二次确认启动生产。接口参数默认收起；A/B/C、事实锁、价格触发、3:4 独立页、历史结果隔离等规则由系统内部承担。
