## 已实现

- 素材生产默认打开 `01-素材库`，递归识别同时包含图片和文案的帖子文件夹。
- 素材树支持紧凑列表和小图标视图；每个有效帖子可“传 GPT”。
- 工作台不再把内嵌网页作为主要 GPT 登录方案；“生产数字作品”使用正常浏览器里的独立扩展，避免 Google 将自研内嵌浏览器判为不安全。
- 工作台新增独立扩展协作接口，提供授权路径、作品集/作品、素材树、文件流和生产历史只读状态。
- 扩展协作接口支持浏览器私有网络预检，修复真实 ChatGPT 页面访问 `127.0.0.1` 时显示 `Failed to fetch`、路径正确但无法扫描的问题。
- 设置页可查看版本、检查当前版本、打开发布目录/运行数据目录/独立扩展目录和复制诊断信息。
- 作品集直接读取用户选择的本地目录；按 `[泛]`、`[转]`、无标签分类，可切换紧凑列表/网格、展开每个合集并预览图片和文本。
- 作品集前台已删除搜索、单独“小红书可用”“全部已使用”和重复台账详情；手机组只展示整组可用包。
- “发布复盘”入口与页面已删除；聚光和生产日志仍保留在设置的高级入口。
- 分发页后台自动刷新设备状态，显示在线/登记总数，在线设备置顶，离线操作禁用。
- 支持随机补泛流量/团建转化、指定作品包选择在线设备、普通文件或文件夹上传、拖放、进度和取消。
- 作品包分发与普通文件传输都使用可恢复任务；页面显示真实阶段、百分比、停止入口和最终结果，刷新页面后可恢复当前及最近任务。
- 全站确认、错误、输入和完成反馈已改为系统内部弹层；前台不显示软链接、Junction 或原始命令行输出。
- 设备名称可保存本机备注，不改手机端原名。
- 手机分发成功后删除已校验的活动平台 Junction，不再创建抖音归档入口；源作品集始终保留。
- 作品包使用独占 claim + `device-usage-log.csv` + Junction 删除三层防重复；中断时宁可保留 claim 等待核对，也不会自动重发。
- 手机组只显示并抽取“小红书 + 抖音”两个入口同时有效的作品包；任一手机平台用过后整组不可再用，公众号组保持独立。
- 公众号流程为“公众号可用 → 已打开过 → 人工确认 → 上传已完成”。
